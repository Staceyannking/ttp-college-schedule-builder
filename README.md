# ttp-college-schedule-builder
## AI Assistance

I used ChatGPT as a learning and development assistant while building this project. AI was used to:

- Explain React concepts such as `useState`, state management, and event handling.
- Help identify and fix JSX syntax errors.
- Provide guidance on organizing components and project structure.
- Explain how to add and delete courses from state.
- Assist with Tailwind CSS setup and styling suggestions.

All code was reviewed, modified, and implemented by me. AI was used as a learning resource and debugging aid rather than generating the entire project.

## Tailwind CSS

This project uses Tailwind CSS for styling and layout.

### Features implemented with Tailwind:
- Responsive container layout using utility classes.
- Card-style design with borders, rounded corners, and shadows.
- Typography styling for headings and labels.
- Consistent spacing using padding and margin utilities.
- Form styling for inputs and buttons.
